# 🧠 Deep Learning Image Classification

An AI-powered image classification web application built using Python, TensorFlow, EfficientNetV2 and Streamlit.

## 🚀 Launch Live Application

**[👉 Click Here to Open the Image Classifier](https://imageclassification-zspylrwhiu7yxywi82khiy.streamlit.app/)**

## 📌 About the Project

This project uses a pretrained Convolutional Neural Network (CNN) to identify objects in uploaded images.

### Features
- Upload JPG, JPEG and PNG images.
- Classify images using EfficientNetV2B0.
- Display the top three predicted categories.
- Show prediction confidence percentages.
- Use an interactive Streamlit web interface.

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- EfficientNetV2B0
- Streamlit
- NumPy
- Pillow

## 📖 How to Use

1. Click the **Launch Live Application** link above.
2. Upload an image.
3. Click **Classify Image**.
4. View the predictions and confidence scores.

## 📂 Source Code

The Python application is available in `app.py`. The dependencies are listed in `requirements.txt`.

## 🎓 Project Purpose

Demonstrate how convolutional neural networks can be integrated into interactive web applications for image classification.
